# 촬영 HTML 재설계 1차 검수

2026-11-07. 브라우저로 직접 검수. 전체 디자인은 사용자 미승인 상태이며, 후속 가이드를 기다린다. 아래는 디자인 승인이 아닌 기능 검수 결과다.

## 1화

- H1-02 a~f 실제 키 입력: 문제 카드 수 0→1→2→3→4→11, 정상 카드 f에서만 1개.
- 12개 카드 모두 441×272 고정. a~f의 숫자 좌표가 동일. 사유 유무·색상 변경에 따른 밀림 없음.
- 카드의 scrollWidth/scrollHeight와 clientWidth/clientHeight 비교: a~f 모두 내부 넘침 0개. 강남 사유의 `213건`은 하나의 줄바꿈 방지 단위로 유지.
- 재구독률은 분위수 보간 그라데이션. 6%=빨강, 7~8%=주황, 9%=황토색, 10%=노랑/연두, 11~14%=연두 계열, 40%=초록. 동일 값은 동일 RGB. 숫자·% 모두 적용. 이는 상대 색상이며 정상/문제의 새 수치 기준이 아니다.
- 여의도 40%는 카드 안에서 한 번만 표시. f에서 테두리·배경과 숫자 굵기로 강조.
- H1-03 촬영 모드 1920×1080에서 제목 하단 y≈522, 보조 문구 하단 y≈633. 핵심 문구가 상단 2/3(y≤720) 안에 있음.
- 행사 장식 원은 캔버스 바깥으로 의도적으로 연장되며 overflow:hidden으로 잘린다. 텍스트 넘침과 구분한다.

## 공통 조작부

- 14개 화면 각각 해시로 실제 접속해 현재 ID, 초기 상태, 상태 버튼 수, 재생 버튼 활성 조건, 콘텐츠/조작부 분리를 확인.
- 정지 화면의 재생 버튼 비활성, VOC a/b 목록의 재생 비활성, c/d 녹음에서만 재생 가능하도록 정의.
- 화면 목록의 키보드 선택으로 1화에서 5화 H5-02 파일까지 실제 이동 확인.
- 이전/다음 버튼, PageDown/PageUp, a/f 상태 버튼, 초기화 버튼 확인. 초기화 시 a·대기 상태와 문제 카드 0개로 복귀.
- 촬영 모드 버튼으로 조작부와 커서를 숨김. 백틱으로 복귀. 촬영 모드에서는 콘텐츠가 창 전체를 사용.
- H2-06·H2-07 a·H3-05는 1080×1920, 나머지 초기 화면은 1920×1080. 모든 화면에서 조작부가 콘텐츠 아래 별도 영역에 있음.
- 검수 뷰포트: 1920×1080 및 기본 창(약 829×1004). 비율 유지 축소와 조작부 줄바꿈 확인.
