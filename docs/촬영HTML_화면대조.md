## 4. 이번 변경 범위와 확인 지점

- 공통 조작부: 모든 5개 HTML에 화면 번호·이름 선택, 이전/다음, 해당 화면 상태 버튼, 재생·초기화, 현재 상태 표시.
- 조작부는 콘텐츠 아래 별도 공간. 촬영 모드는 조작부·커서를 숨기고 전체 창을 사용. 백틱으로 복귀. `?shoot=1`로 촬영 모드 시작 가능.
- 해시 직접 이동·PageUp/Down·a~f·화살표·Space·R 유지. 입력 선택 요소에서 방향키와 Space는 기본 접근성 조작을 우선한다.
- H1-02는 4×3 고정 카드, 일 주문·재구독률 라벨, 단위 붙임, 고정 사유 자리, 최종 여의도 40% 한 번만 표시·강조.
- 사용자 후속 수정: 재구독률 숫자는 단순 초록/빨강 이분법 대신 빨강→주황→노랑→연두→초록의 연속 그라데이션. 현재 데이터의 분위수 사이를 보간해 6~14%에 몰린 값도 구분하고, 같은 값은 같은 색을 사용한다. 이 상대 색상은 새로운 성과 판정 임계값이 아니며 카드 테두리의 대본상 a~f 상태와 별개다.
- H1-03는 회사·서비스·출시 선언 위계, 상단 2/3 핵심 문구, 크림슨 바탕과 12권역 추상 장식. 문구는 원문 유지.
- 생성기는 공통 런타임·CSS·1화 렌더러를 조합하고, 화면 목록·상태·1화 문구·색·수치는 JSON에서 읽는다. 나머지 12개 화면의 시각 디자인은 아직 기존 초안이다.

**사용자는 전체 디자인에 동의하지 않았고 상세 가이드를 추후 제공하기로 했다. 이 PR은 미승인 초안 보관용 Draft다. 그라데이션 수정과 공통 조작부까지만 검수하고, 3단계의 나머지 화면별 디자인은 가이드 확인 후 진행한다.** main 직접 push·merge는 하지 않는다.
